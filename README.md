# Daily Work Log Skill

A public, generic template and agent skill for keeping a lightweight daily work log.

The goal is to capture useful work evidence in 5 minutes per day, then reuse it later for weekly summaries, project updates, brag docs, performance reviews, and self-reflection.

## What This Is

- A reusable work-log template.
- A simple AI-agent skill for turning rough daily notes into structured work logs.
- A safe public reference that contains no employer-specific, customer-specific, or confidential information.

## What This Is Not

- Not a private diary.
- Not a company-specific reporting system.
- Not a place to store internal project names, confidential metrics, customer data, credentials, or unreleased information.

## Files

- `skill/daily-work-log/SKILL.md`: agent skill instructions.
- `templates/daily-work-log.md`: daily work log template.
- `templates/weekly-summary.md`: weekly summary template.
- `templates/brag-doc.md`: brag doc template.
- `examples/sanitized-daily-work-log.md`: safe generic example.
- `guides/leadership-sync-playbook.md`: public-safe guide for ownership and project sync conversations.

## Quick Use

1. Copy `templates/daily-work-log.md`.
2. Rename it to `YYYY-MM-DD.md`.
3. Spend 5 minutes filling the sections.
4. At the end of the week, use `templates/weekly-summary.md`.

## Privacy Rule

Before saving or sharing a work log, remove or generalize:

- employer names if not appropriate;
- internal project code names;
- unreleased product details;
- customer data;
- incident details;
- private metrics;
- credentials, tokens, or links to restricted systems.

Prefer descriptions like “project milestone,” “cross-team sync,” “design review,” and “debugged a production issue” unless a specific name is safe to record.
